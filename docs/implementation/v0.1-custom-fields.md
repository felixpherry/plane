# v0.1 — Custom Fields Implementation

> Phase 1 of the Plane fork. Adds custom field properties to issues — the #1 community-requested feature missing from Community Edition.

## Backend

- [x] Django models: `CustomField` + `CustomFieldValue` extending `WorkspaceBaseModel`
- [x] `FieldType` enum: text, number, select, multi_select, date, checkbox, url
- [x] `is_active` field for enable/disable without deleting
- [x] API key auth serializers (`plane.api.serializers.custom_field`)
- [x] API key auth views + URLs (`/api/v1/.../custom-fields/`, `/api/v1/.../custom-values/`)
- [x] Session auth views + URLs (`/api/.../custom-fields/`, `/api/.../custom-values/`)
- [x] Type-specific validation in serializers (select options, url format, number type, etc.)
- [x] Bulk upsert for custom field values (POST array)
- [x] Soft delete cascade (deleting field soft-deletes all values)
- [x] Register models in `db/models/__init__.py` (including `FieldType`)
- [x] Register serializers in `api/serializers/__init__.py`
- [x] Register views in `app/views/__init__.py` and `api/views/__init__.py`
- [x] Register URLs in `app/urls/__init__.py` and `api/urls/__init__.py`
- [x] Database migration applied (direct SQL for `is_active` column)

## Frontend — Types + Services

- [x] `packages/types/src/custom-field.ts` — interfaces, enums, payload types
- [x] `packages/services/src/custom-field/custom-field.service.ts` — 9 API methods
- [x] Value type changed from `Record<string, unknown>` to `unknown`

## Frontend — Issue Sidebar (view + edit values)

- [x] `CustomFieldsSection` component — fetches fields + values, optimistic updates
- [x] `CustomFieldProperty` component — renders per-type input using `SidebarPropertyListItem`
- [x] `SelectInput` — `ComboDropDown` + `DropdownButton` + `useDropdown` + `usePopper` (matches MemberDropdown)
- [x] `TextInput` — `Input` from `@plane/ui` with click-to-edit
- [x] `NumberInput` — `Input type="number"` from `@plane/ui`
- [x] `CheckboxInput` — `Checkbox` from `@plane/ui`
- [x] `UrlInput` — `Input type="url"` with external link display
- [x] `DateDropdown` — reuses Plane's built-in `DateDropdown` component
- [x] Multi-select support with toggle, stays open, badge display
- [x] Multi-select colored badges with deterministic hash (8 colors, max 3 + N more)
- [x] `prependIcon` prop on `CustomFieldSelectInput`
- [x] Wired into `peek-overview/properties.tsx` (peek panel)
- [x] Wired into `issue-detail/sidebar.tsx` (full detail page)
- [x] Optimistic updates only (no re-fetch on success, revert on error)
- [x] i18n key: `common.custom_properties`
